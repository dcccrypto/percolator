## What a stub can and cannot do to a statement

- STUB-OK and STUB-FRAME stubs return `Ok(())` where the engine may return `Err`, and write nothing that is in the slice. A statement of the form "if the call returns `Ok` then ..." about the slice therefore covers every engine run that returns `Ok` (on the covered path, see STUB-PATH); the engine may additionally fail there. A statement "does not return `Err`" (RC3s) does **not** transfer: it is about the slice's code only.
- STUB-PATH (`burn_account_source_claim_bound_num`): see D4 (c). This is a restriction on which engine runs are covered, not only on `Err`.
- The second half of `Inv` being true whenever the engine reaches the tail is not shown anywhere (D2).
